# Leviathan для macOS (Apple Silicon)

Leviathan — клиент DDNet 20.1 со своим набором дополнений поверх игры:
автоматический анфриз-выстрел, трейлы за тишками, 3D-каркасы, дрейфующие за
картой, эффектные лучи лазера, шапки, режим концентрации, который убирает с
экрана всё, кроме игры, градиентный текст, музыкальный островок с тем, что
играет в системе, друзья и враги с цветными точками, авто-ответы, свои фоны
(картинки и видео), цвета тайлов, свой прицел, цвет крюка, Discord-статус с
кнопкой Telegram, значок у игроков на Leviathan и вкладка настроек, где всё это
собрано в одном месте.

Это **сборка для macOS на Apple Silicon (arm64)**. Она собирается из того же
дерева исходников, что и Windows-клиент, коммит в коммит: всё, что не касается
операционной системы, общее, а то, что касается, лежит в отдельных файлах. Оба
клиента выглядят и ведут себя одинаково, потому что это одна программа.

## Требования

- Mac на Apple Silicon (M1 и новее). Под Intel не собирается.
- macOS 11 (Big Sur) или новее — первая macOS, которая вообще работает на Apple
  Silicon. Целевая версия самого бинарника — 10.15.
- Больше ничего ставить не нужно: бандл несёт все библиотеки с собой.

## Установка релиза

1. Скачай `Leviathan-<версия>-macos.dmg` со страницы Releases.
2. Открой образ и перетащи `Leviathan.app` в `Программы`.
3. Приложение не подписано и не нотаризовано, поэтому macOS в первый раз его не
   пустит. Два пути:
   - открой **Системные настройки → Конфиденциальность и безопасность**,
     найди строку про заблокированный Leviathan и нажми **Открыть всё равно**;
   - или в Терминале: `xattr -dr com.apple.quarantine /Applications/Leviathan.app`
4. Запускай из `Программ`.

Если не запускается — на macOS клиент по умолчанию пишет лог в
`~/Desktop/Leviathan.log`. Это первое, куда стоит заглянуть, и первое, что стоит
прислать, когда просишь помощи.

## Сборка из исходников

Всё ниже делается в Терминале.

```bash
# Инструменты командной строки Xcode, если их ещё нет
xcode-select --install

# Сборочные инструменты и библиотеки, которые будет искать CMake
brew install cmake ninja pkg-config sdl2 ffmpeg
brew upgrade freetype
python3 -m pip install --break-system-packages dmgbuild pyobjc-framework-Quartz

# Готовые библиотеки, которые едут внутри бандла (не сабмодуль)
git clone https://github.com/sdenar228-alt/Leviathan-macos.git
cd Leviathan-macos
git clone --depth 1 https://github.com/ddnet/ddnet-libs ddnet-libs

# Конфигурация и сборка клиента
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DPREFER_BUNDLED_LIBS=ON \
  -DCLIENT_EXECUTABLE=Leviathan \
  -DDISCORD=ON
cmake --build build --target game-client

# По желанию: .app и образ диска
cmake --build build --target package_dmg
```

`PREFER_BUNDLED_LIBS=ON` важен. Без него CMake берёт freetype, png, opus и ogg
из Homebrew, а их dylib несут абсолютные пути `/opt/homebrew` — и полученное
приложение запускается только на машине, где Homebrew стоит по тем же путям.

Для Debug-сборки — `-DCMAKE_BUILD_TYPE=Debug` и другая папка сборки.

## Запуск из папки сборки

```bash
cd build
./Leviathan
```

Папку `data/` клиент находит рядом с исполняемым файлом. Настройки пишутся в
`~/Library/Application Support/DDNet/` — туда же, куда и обычный DDNet, так что
его конфиг подхватывается как есть.

## Что отличается на macOS

- **Музыкальный островок** читает, что играет, через системный сервис Now
  Playing. Начиная с macOS 15.4 читаются только Spotify и Музыка, и в первый раз
  система спросит разрешение.
- **Видеофоны** декодируются через AVFoundation; картинки (png, jpg, bmp, webp,
  heic) и видео (mp4, mov, m4v) работают.
- **Discord-статус** общается с приложением Discord через его unix-сокет, а не
  через именованный канал. Те же кнопки, та же картинка.
- **Лог** идёт в `~/Desktop/Leviathan.log`, пока не задан `logfile`.
- **Графика** — OpenGL 3.3. Vulkan-бэкенд на macOS не собирается.

## Известные ограничения

- Приложение не подписано. Каждую свежую загрузку нужно один раз пропустить
  через Gatekeeper (см. «Установка»).
- Только Apple Silicon. Ни Intel-сборки, ни универсального бинарника нет.
- Свой шейдер тишки (`shader/tee.frag`) требует OpenGL 3.3 — на нём клиент по
  умолчанию и стартует.

## Как делался порт

В `PORTING_LOG.md` перечислена каждая проблема, встреченная по дороге к macOS:
её причина, исправление и то, как исправление проверялось. Там же прямо сказано,
какие части проверены только автоматической сборкой, а не человеком за маком.

## Лицензия

На всё дерево, включая эту сборку, действует лицензия самого DDNet — см.
`license.txt` в корне репозитория.

## Автоматические сборки

`.github/workflows/macos-app.yml` собирает клиент на раннерах с Apple Silicon в
Release и Debug, прогоняет headless-клиент через запуск и выход и упаковывает
Release-сборку в образ диска, который публикуется на странице Releases.
