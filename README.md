# Leviathan

Клиент DDNet 20.1 со своими дополнениями поверх игры. Собирается под
**Windows** и **macOS (Apple Silicon)** из одного дерева исходников — оба клиента
одинаковы, потому что это одна программа.

- Telegram: <https://t.me/leviathanddnet>
- Сборки для Windows и macOS: [Releases](https://github.com/sdenar228-alt/Leviathan-/releases)
- Отдельный репозиторий macOS-сборки: <https://github.com/sdenar228-alt/Leviathan-macos>

## Что добавлено

Всё настраивается во вкладке **Leviathan** в настройках (или из консоли F1).

- **Анфриз-выстрел** — клиент сам находит, как разморозить тебя твоим же
  лазером: рисует план или стреляет по кнопке.
- **Трейл тии** — лента за тишкой, с цветом, шириной, длиной и затуханием.
- **3D-частицы** — каркасные кубы, сердца, круги, шестиугольники и треугольники,
  плывущие за картой, с объёмом и свечением.
- **Эффектное оружие** — кристальный лазер и песочный дробовик с искрами вдоль
  луча.
- **Шапки** — корона, рожки, нимб и любой свой png из папки `hats`.
- **Режим концентрации** — одна клавиша убирает с экрана всё, кроме игры.
- **Градиентный текст** — в игре и в меню, со скоростью, цветом, разбросом и
  яркостью; чёрный переливается чёрно-белым.
- **Плашка клиента** — логотип, название и системные часы над таймером.
- **Авто-ответ** — игрокам в мьюте и когда ты не в игре, своими словами.
- **Игроки Leviathan** — логотип у ника и в таблице у всех, кто на этом клиенте.
- **Друзья и война** — зелёная и красная точки у ника, `!war ник` прямо из чата.
- **Музыкальный островок** — что играет в системе, с кнопками и обложкой.
- **Фон** — картинка или видео за игрой и меню; цвет и тема самого меню.
- **Цвета тайлов, свой прицел, цвет крюка, обводка тишки, аватарка вместо тела,
  шейдер тишки, звуковые паки, модели оружия из других паков.**
- **Discord-статус** с кнопкой Telegram.
- **Переключение языка RU / EN** прямо в главном меню.

Подробно о каждой функции и о том, как она устроена: [LEVIATHAN.md](LEVIATHAN.md)
(по-английски: [LEVIATHAN.en.md](LEVIATHAN.en.md)).

## Сборка

**Windows** (Visual Studio с C++, CMake, Ninja):

```
build.bat
```

Результат — `build\Leviathan.exe` с папкой `data` рядом.

**macOS** — см. [docs/README.macos.md](docs/README.macos.md): требования,
зависимости, команды CMake и упаковка в `.dmg`. Порт описан в
[PORTING_LOG.md](PORTING_LOG.md).

`ddnet-libs` в репозиторий не входит — клонируется рядом:

```
git clone --depth 1 https://github.com/ddnet/ddnet-libs
```

## Установка готовой сборки

- **Windows:** распаковать архив из Releases и запустить `Leviathan.exe`.
- **macOS:** открыть `.dmg`, перетащить `Leviathan.app` в Программы и один раз
  разрешить запуск в «Конфиденциальность и безопасность → Открыть всё равно».

Настройки хранятся там же, где у обычного DDNet (`%APPDATA%\DDNet` на Windows,
`~/Library/Application Support/DDNet` на macOS), так что его конфиг подхватится.
